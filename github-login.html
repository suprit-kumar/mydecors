Browser security note

This static page sends your token only to GitHub’s API and keeps it in this tab’s JavaScript memory. It is not saved to localStorage or sent to our website server. A browser-based token can still be exposed by malicious scripts, extensions, or other users on a shared device. Use this only in a trusted browser and revoke the token when you no longer need it.

01Recommended token permissions
  • Repository access: Only select the repository you intend to use.
  • Contents: Read and write.
  • Metadata: Read-only (required by GitHub).

GitHub has no non-mutating endpoint to inspect a Fine-grained PAT’s Contents: write grant. Repository push access is checked, but you must confirm Contents: Read and write in GitHub token settings. No test commit is made.

Token security

Your token remains only in this page’s memory and is sent only to GitHub’s API. Logging out, reloading, or closing this tab clears it. GitHub does not expose a safe read-only test for the token’s write permission.
